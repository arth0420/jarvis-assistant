Jarvis Assistant: Privacy Policy
Jarvis Assistant is a personal, locally-run voice assistant. It uses Google sign-in to access the user's own Gmail, Google Calendar and Google Contacts, only to perform actions the user requests (reading, sending or archiving email, managing events, looking up contacts).
All data is processed on the user's own computer. The sign-in token is stored locally on that computer. No Google user data is collected, sold, shared with third parties, or used for advertising or AI model training.
The user can revoke access at any time at myaccount.google.com/permissions.
